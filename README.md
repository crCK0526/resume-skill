# 简历优化 SKILL + 知识库 · 通用使用说明书

> 一套开源的通用简历制作工具：适用于任何行业、任何岗位、任何人。
>
> 免费使用 · 建议使用 KIMI 制作简历

**本工具希望帮助每一位正在求职的人——无论是即将毕业、正在找工作的学生（应届生），还是已经工作的社会人员，或是暂时失业、正在重新出发的求职者，都能把零散材料变成一份专业、可信、可编辑的 A4 中文简历。**

## 一、这是什么

这是一套可复用的简历制作资源，包含一个技能（SKILL）和一套配套知识库。任何人下载后，都能用自己（或他人）的证书、奖状、经历等材料，生成一份 **A4 单页、可编辑的中文 PPT 简历**。它不是某个人的专属模板，而是通用工具。

核心理念是「证据驱动」：每一条简历陈述都能追溯到原始材料；冲突不靠猜、缺失如实标注、绝不编造数据；成品经过渲染目检后才算完成。

## 二、适用人群

本工具主要面向三类正在求职的人：

- 应届毕业生与在校学生：缺乏工作经验，需要把实习、校园经历、竞赛与证书转化为有力表达。
- 社会人员：在职转岗、跳槽或重返职场，需要系统梳理经历与技能。
- 失业人员：暂时待业、重新求职，需要快速整理一份标准、可信的简历。

此外，简历代写、职业辅导、HR 辅助等从业者，以及需要批量产出标准简历的个人或团队同样适用；已覆盖互联网产品 / 开发 / 设计 / 运营 / 数据分析、金融、咨询、考公、留学等 9 大行业（可扩展）。

## 三、核心能力

- 证据提取：从多份材料中抽取事实，逐条记录来源与置信度。
- 冲突解决：交叉核对矛盾信息，缺失与冲突显式标注，不擅自“修正”。
- JD 分析：从岗位描述中提取关键词，并映射到简历措辞。
- 行业措辞：按目标行业套用术语与表达规范。
- 质量评分：以 HR 评分维度做内部质检（分数仅作参考，不代表录用结果）。
- 视觉复刻：复刻参考简历的版式，或套用三套内置风格。
- 可编辑交付：A4 单页 PPT，正文最小字号 9pt，全部元素可编辑。

## 五、安装与配置（Windows / macOS / Linux 通用）

1. 获取本仓库：下载解压，或执行 `git clone`。
2. 安装 SKILL：将 `evidence-resume-ppt` 文件夹放入你 AI 助手（如 KIMI）的 skills 目录。
3. 配置知识库路径：打开 `evidence-resume-ppt/SKILL.md`，把默认绑定路径 `E:\简历知识库` 全部替换成你本地的实际路径，例如 `D:\resume-skill\简历知识库` 或 `/home/you/resume-skill/简历知识库`。
4. 触发：对助手说「根据这些证书和资料整理一份简历」，并附上材料。

## 六、完整制作流程（九步）

1. 清点材料：列出所有输入；图片按原方向读取，Office 文件用脚本提取并重建阅读顺序。
2. 建立证据台账：为每条事实记录分类、陈述、来源、置信度、状态与备注。
3. 解决冲突：官方记录优先；发证机构只证明发证方，不等同于毕业院校；缺失如实标注。
4. 检索岗位知识：按目标岗位读取 ATS 规范、行业术语与 JD 关键词。
5. 起草文案：按「动作 + 职责 + 结果」写要点，用简洁中文，避免空洞形容词。
6. 分析参考风格：只提取版式、配色、字体、层级等可复用的设计属性，不复制他人隐私内容。
7. 生成 PPT：A4 竖版、单页、浅色底、可编辑、正文不小于 9pt。
8. 渲染检查：整页与 100% 缩放目检，重点看溢出、缺字、字体替换与层级。
9. 评分交付：用 HR 评分做内部质检，产出 PPT 与预览图，并说明已确认内容与待确认项。

## 七、知识库检索顺序

1. 判断任务类型、目标岗位、资历与目标市场。
2. 先读通用规则（ATS 结构或 HR 评分），再读与岗位最匹配的一份行业术语。
3. 有 JD 时，读 JD 关键词匹配指南。
4. 候选事实提取完成后，再读范例，防止虚构范例污染证据台账。
5. 每次应用规则都在内部备注引用文件路径，最终回到原始证据做事实复核。

## 八、三种视觉风格

- Pack A 专业蓝：通用校招 / 投递主版本，浅色单栏、ATS 友好。
- Pack B 低饱和创意：新媒体 / 设计 / 内容运营展示版，允许受控双栏。
- Pack C 影视暗色：AI 影视 / 导演展示版，需配套浅色 ATS 版本。

## 九、合规与隐私边界

- 知识库只含结构与措辞规则，不含真实个人信息，范例均为虚构人物。
- 候选人事实只能来自用户材料或明确更正，绝不来自知识库示例。
- 简历中的手机、邮箱、证件号等个人信息只进入成品文件，不进聊天摘要。
- 默认本地处理；任何外部或云端处理前，须披露传输内容、用途与留存，并取得授权。

## 十二、常见问题

- 换了电脑或系统能用吗？能，只要把 `SKILL.md` 里的知识库路径改成新位置即可。
- 知识库路径不对会怎样？SKILL 会自动降级为内置指引并提示，但仍建议配置正确路径。
- 证书图片读不出文字？模型无视觉时，以简历文本与文件名核对，重要字段标「待确认」。
- 生成结果能直接投递吗？建议先人工确认事实与排版；ATS 投递使用浅色单栏版。
