# 简历优化 SKILL + 知识库（免费使用）

一套“证据驱动”的中文简历制作资源，包含：

- `evidence-resume-ppt/` — 简历生成 SKILL：把零散证书、奖状、材料整理为 A4 单页、可编辑的 PPT 简历。
- `简历知识库/` — 配套知识库：ATS 规范、HR 评分、行业术语、JD 匹配、简历范例、求职信、面试准备等。

## 许可

免费使用（MIT License）。可自由使用、复制、修改和分发。

## 推荐工具

建议使用 KIMI 制作简历。

## 快速开始

1. 将 `evidence-resume-ppt` 放入你的 AI 助手（如 KIMI）的 skills 目录。
2. 保持 `简历知识库` 路径不变，或在 `evidence-resume-ppt/SKILL.md` 中修改绑定路径 `E:\简历知识库`。
3. 对助手说：根据这些证书和资料整理一份简历。

## 说明

- 知识库只提供结构与措辞规则，不含任何真实个人信息，范例均为虚构人物。
- 详情见 `evidence-resume-ppt/SKILL.md` 与 `简历知识库/使用说明.md`。
