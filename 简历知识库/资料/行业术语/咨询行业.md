## 四、Case Interview 核心题型

### 4.1 四大题型
- **Market Sizing（市场规模估算）**
  - 例：上海一年卖多少咖啡？
  - 方法：自上而下 / 自下而上 / 供需平衡
- **Profitability（盈利问题）**
  - 例：某产品利润下降 20%，怎么分析？
  - 方法：收入 - 成本 拆解 → 找根因
- **Market Entry（市场进入）**
  - 例：某企业是否应该进入印度市场？
  - 方法：市场吸引力 + 进入能力 + 风险
- **M&A（并购）**
  - 例：某公司是否应该收购 X？
  - 方法：战略协同 + 财务可行性 + 整合风险

### 4.2 进阶题型
- **Pricing（定价）**
- **New Product（新业务）**
- **Competitive Response（竞争应对）**
- **Cost Reduction（成本削减）**
- **Operations（运营优化）**
- **Organization（组织设计）**
- **Digital Transformation（数字化转型）** 2026 热点

### 4.3 Case 框架
- **MECE 原则**：相互独立、完全穷尽
- **金字塔原理 (Pyramid Principle)**：Barbara Minto
- **假设驱动 (Hypothesis-Driven)**：先假设再验证
- **4C / 4P / 5C / 波特五力**等经典框架

### 4.4 2026 热点话题
- **AI / 生成式 AI 的商业化**
- **ESG / 可持续发展**
- **新能源 / 储能 / 光伏**
- **跨境电商 / 出海**
- **半导体 / 国产替代**
- **医疗健康 / 创新药**
- **Web3 / 区块链**
- **数字化转型**

## 五、案例面试核心方法

### 5.1 Market Sizing 范例
**题目**：上海一年卖多少杯咖啡？

**思路**（自下而上）：
```
1. 人口基数：2400 万常住人口
2. 咖啡消费人群占比：约 30%（一线城市年轻人）
   → 720 万人
3. 人均月消费频次：约 8 次（每周 2 杯）
4. 单价：25 元
5. 年总销量 = 720 万 × 8 × 12 × 25 = 1728 亿元
```

### 5.2 Profitability 范例
**题目**：某连锁餐厅利润下降 30%，怎么分析？

**思路**：
```
1. 利润 = 收入 - 成本
2. 收入 = 客单价 × 客流量
3. 客单价下降？→ 套餐结构 / 折扣策略 / 客群变化
4. 客流量下降？→ 竞争 / 口碑 / 选址 / 经济环境
5. 成本上升？→ 食材 / 人工 / 房租 / 营销
6. 进一步：哪个分店？哪个时段？哪个菜品？
```

### 5.3 答题流程
1. **重述问题**（30 秒）
2. **澄清问题**（1-2 分钟）：问清楚范围 / 目标
3. **提出框架**（2-3 分钟）：MECE 拆解
4. **深入分析**（10-15 分钟）：每点用 1-2 句话论证
5. **总结 + 建议**（2 分钟）：回答原问题，给出 actionable 建议

## 七、咨询面试流程详解

### 7.1 MBB 标准流程
1. **网申**（8-10 月）
2. **Online Test**（逻辑题 + 数学题）
3. **Pretalk / 第一轮**（1-2 个 Case + Fit）
4. **Superday / Final Round**（3-4 个 Case + 2-3 个 Fit）
5. **Offer**

### 7.2 时间线
- **7-8 月**：网申开放
- **9-10 月**：Pretalk
- **10-11 月**：Superday
- **12 月 - 次年 1 月**：Offer 发放
- **次年 2-3 月**：实习（夏季）
- **8-9 月**：Return Offer

## 十、咨询行业 AI 时代转型

### 10.1 AI 改变的咨询工作
- **基础研究**：AI 自动搜集整理
- **PPT 制作**：AI 生成初稿
- **数据分析**：AI 处理标准化
- **行业研究**：AI 生成框架

### 10.2 咨询人核心价值（AI 难以替代）
- **客户关系**：高层沟通、信任建立
- **复杂问题结构化**：跨领域问题分解
- **项目推动**：跨部门协调
- **战略判断**：基于经验 + 直觉的决策
- **变革管理**：推动客户内部改变

### 10.3 转型方向
- **战略 + AI**：AI 战略咨询
- **行业专家**：垂直深度（医疗 / 金融 / 科技）
- **数据驱动咨询**：从数据中找洞察
- **解决方案专家**：帮客户落地，不只是 PPT
