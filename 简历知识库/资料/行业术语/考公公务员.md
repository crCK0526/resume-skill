# 考公/公务员/事业单位 - 专业术语词典

> 适用岗位：公务员、选调生、事业单位、国企、军队文职
> 适用人群：应届毕业生、往届生
> 整理日期：2026-09-02

---

## 一、考公政策核心信息

### 1.1 应届生身份界定（2026 最新）
- **2026 届毕业生**：2026 年 7 月前取得毕业证的应届生
- **择业期 2 年**：未落实工作单位的毕业生可保留应届身份 2 年
- **应届身份优势**：
  - 约 60-70% 国考岗位限应届生
  - 户籍限制放宽
  - 基层工作经历豁免
  - 竞争比 30:1（往届 80:1）

### 1.2 国考 / 省考 / 事业单位区别
| 类型 | 招录时间 | 报名条件 | 考试内容 |
|---|---|---|---|
| **国考** | 10 月报名，11-12 月笔试 | 大专以上，应届/往届均可 | 行测 + 申论 + 专业课 |
| **省考** | 1-3 月报名，3-4 月笔试 | 大专以上，限本省户籍多 | 行测 + 申论 |
| **选调生** | 11-12 月报名 | 仅限应届生，党员/学生干部 | 行测 + 申论 + 面试 |
| **事业单位** | 全年分散 | 大专以上，条件各异 | 公基 / 行测 + 申论 / 专业课 |
| **国企** | 全年 | 学历要求高，专业对口 | 行测 + 申论 + 性格测试 |
| **军队文职** | 全年 | 学历要求高 | 公共科目 + 专业课 |

## 二、行测（行政职业能力测验）核心模块

### 2.1 五大模块
- **常识判断**（20 题）
  - 法律 / 政治 / 经济 / 人文 / 科技 / 地理
  - 时事政治（重要会议、政府工作报告）
- **言语理解与表达**（40 题）
  - 逻辑填空 / 阅读理解 / 语句排序 / 病句辨析
- **数量关系**（15 题）
  - 数学运算（行程、工程、利润、排列组合）
  - 数字推理（数列、图形）
- **判断推理**（40 题）
  - 图形推理（点线面、位置、对称）
  - 定义判断
  - 类比推理
  - 逻辑判断（加强、削弱、假设、推出）
- **资料分析**（20 题）
  - 文字资料 / 表格资料 / 图形资料
  - 增长率 / 比重 / 倍数 / 平均数

### 2.2 行测高分策略
- **资料分析**：保证 90% 正确率（提分最快）
- **判断推理**：图形推理 + 逻辑判断 85%+
- **言语理解**：刷题量是关键
- **数量关系**：选择性放弃（耗时高）
- **常识判断**：靠平时积累

## 三、申论核心题型

### 3.1 五大题型
- **归纳概括题**：概括材料主要内容
- **提出对策题**：针对问题提出解决方案
- **综合分析题**：分析现象 / 观点 / 关系
- **贯彻执行题**：写讲话稿、倡议书、工作方案
- **大作文**：议论文（1000 字左右）

### 3.2 申论三段式写作
- **问题 → 对策 → 成效**（最常见结构）
- **开头点题**：引用政策/数据/名言
- **分论点论证**：3-4 个分论点，每点 200 字
- **结尾升华**：呼应主题 + 展望

### 3.3 申论热点话题（2026）
- **高质量发展 / 新质生产力**
- **数字经济 / 人工智能 +**
- **乡村振兴 / 共同富裕**
- **生态文明 / 绿色发展**
- **文化自信 / 中华优秀传统文化**
- **基层治理 / 民生保障**
- **就业优先 / 青年发展**
- **科技创新 / 自主可控**

## 四、面试核心题型

### 4.1 结构化面试（最常见）
- **综合分析题**：社会现象、政策理解、名言警句
- **组织计划题**：调研、宣传、活动策划
- **人际关系题**：与领导、同事、群众冲突
- **应急应变题**：突发情况处理
- **自我认知题**：自我介绍、职业规划
- **岗位匹配题**：为什么报考这个岗位

### 4.2 无领导小组讨论
- **角色**：破冰者 / 领导者 / 时间管理者 / 总结者
- **题型**：排序题 / 资源争夺 / 方案设计
- **评分标准**：发言次数 + 逻辑 + 协作 + 创新

### 4.3 面试答题框架
- **表态 → 分析原因 → 提出对策 → 总结升华**
- **STAR 法则**：情境-任务-行动-结果
- **举实例 + 谈感悟 + 落岗位**

## 五、考公简历包装方法

### 5.1 应届生考公简历的核心思路
- **没有实习经历就突出：**
  - 学生干部 / 社团管理经验
  - 党团活动 / 主题教育参与
  - 志愿服务 / 公益活动
  - 校内实践 / 课题研究
  - 文体活动 / 竞赛获奖

### 5.2 考公备考经历的正确写法
❌ **错误**：「2025.10-2026.3 备考公务员」
✅ **正确**：
```
- 行测备考：熟练掌握资料分析、逻辑推理技巧，具备数据梳理、快速决策、逻辑拆解能力
- 申论备考：熟练撰写公文、议论文、材料总结，具备文字撰写、信息归纳、政策理解能力
- 长期独立备考，每日高效学习 6+ 小时，具备极强的自律性、抗压能力、目标执行力
```

### 5.3 应届生加分项写法
- **学生干部经历**：
  - "担任学生会主席，统筹 200+ 成员的年度活动，锻炼组织协调能力"
- **党员 / 预备党员**：在政治面貌栏注明
- **奖学金 / 三好学生**：体现学习能力
- **志愿服务时长**：突出奉献精神
- **实习经历**：基层岗位经验是加分项

### 5.4 自我评价模板
```
本人为 2026 届应届毕业生，性格踏实稳重，具备较强的政治素养和文字写作能力。
- 立场坚定：积极向党组织靠拢，具有正确的世界观、人生观、价值观
- 自律性强：长期坚持高强度学习（公务员备考 4 个月，每日 6+ 小时）
- 文字功底：大学期间撰写论文、报告 30+ 篇，擅长公文写作
- 群众观念：积极参加志愿服务，累计服务时长 200+ 小时
- 抗压能力：面对复杂局面能保持冷静，快速找到解决方案
```

## 六、各类公职考试岗位推荐

### 6.1 国考热门岗位
- **税务系统**：招录大户（约 40%）
- **海关系统**：待遇好，专业要求严
- **银保监 / 证监 / 审计**：金融财经类
- **铁路公安**：公安干警
- **海事局 / 边检**
- **统计系统**
- **外交部 / 商务部**：外交部待遇高
- **中央部委办公厅**

### 6.2 选调生（应届生专属）
- **定向选调**：面向 985/211 重点高校
- **非定向选调**：面向普通高校
- **优势**：晋升快、起点高、培养机制好

### 6.3 事业单位方向
- **教育系统**：学校教师 / 教育局
- **医疗系统**：医院 / 卫健委
- **科研院所**
- **新闻媒体**：电视台、报社
- **建设规划**：住建局、规划院

## 九、考公避坑指南

### 9.1 选岗避坑
- ❌ 三不限岗位（竞争激烈）
- ❌ 异地乡镇岗（5 年服务期）
- ❌ 招录人数 1 人的岗位（偶然性大）
- ✅ 限制条件多 + 招录人数多 + 地理位置合适

### 9.2 备考避坑
- ❌ 盲目刷题不总结
- ❌ 报太多班不消化
- ❌ 临考 1 个月才开始
- ✅ 系统学习 + 真题 + 模考 + 复盘

### 9.3 心态管理
- ❌ 全职备考 1 年以上（压力过大）
- ❌ 考公失败就放弃所有其他机会
- ✅ 考公 + 秋招 + 春招 多线并行
