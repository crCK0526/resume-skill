## 三、SQL 必备技能（最核心）

### 3.1 基础
- `SELECT / FROM / WHERE / GROUP BY / HAVING / ORDER BY`
- `JOIN`（INNER, LEFT, RIGHT, FULL）
- `UNION / INTERSECT`
- 子查询、聚合函数

### 3.2 进阶（必须掌握）
- **窗口函数**：
  - `ROW_NUMBER() / RANK() / DENSE_RANK()`
  - `LAG() / LEAD()`（环比）
  - `SUM() OVER / AVG() OVER`（累计、移动平均）
  - `NTILE() / PERCENT_RANK()`
- **CTE（Common Table Expressions）**：`WITH ... AS`
- **递归 CTE**：组织树、推荐链
- **Pivot / Unpivot**：行列转换
- **日期函数**：`DATE_TRUNC / EXTRACT / DATEDIFF`
- **正则表达式**
- **性能优化**：`EXPLAIN`、索引、分区

### 3.3 简历中 SQL 怎么写（重要）
- ❌ "熟练使用 SQL"
- ✅ "**熟练使用 SQL（窗口函数、CTE、查询优化），在 BigQuery 中处理日均 10 亿行数据**"
- ✅ "**使用 SQL 编写复杂漏斗分析查询，识别 12 个关键流失节点，节省人工 30 小时/周**"

## 四、Python 数据分析必备技能

### 4.1 核心库
- **Pandas**：DataFrame、数据处理
- **NumPy**：数值计算
- **Matplotlib / Seaborn**：可视化
- **Plotly / Bokeh**：交互式图表
- **Scikit-learn**：机器学习基础

### 4.2 数据分析全流程
```python
# 标准数据分析流程
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 1. 数据加载
df = pd.read_sql(query, connection)

# 2. 数据清洗
df = df.dropna().drop_duplicates()

# 3. 探索性分析
df.describe()
df.groupby('category')['sales'].agg(['sum', 'mean'])

# 4. 业务洞察
insight = df.groupby('month')['revenue'].sum().pct_change()

# 5. 可视化
df.plot(kind='bar', title='Monthly Revenue')

# 6. 自动化报表
df.to_excel('monthly_report.xlsx')
```

## 六、A/B 测试核心知识

### 6.1 实验设计
- **假设检验**（H0 / H1）
- **样本量计算**（power analysis）
- **随机化分桶**
- **对照组 vs 实验组**
- **单变量 vs 多变量测试**

### 6.2 关键指标
- **P-value**：小于 0.05 表示显著
- **置信区间**：95% 置信度
- **统计功效（Power）**：通常 80%
- **MDE（Minimum Detectable Effect）**

### 6.3 常见陷阱
- **辛普森悖论**
- **新奇效应 / 初学者运气**
- **多重比较问题**（Bonferroni 校正）
- **A/A 测试**：验证实验系统稳定

## 十一、AI 时代数据分析师的进化

### 11.1 AI 改变的工作
- **写 SQL**：AI 自动生成（Copilot）
- **基础可视化**：AI 一键出图
- **数据清洗**：自动化脚本
- **报告初稿**：AI 写

### 11.2 不可替代的价值
- **业务理解**：知道"为什么"比"是什么"重要
- **数据故事**：把数字变成决策
- **复杂因果分析**：AI 难以处理多变量因果
- **利益相关者管理**：跨部门沟通协调
- **领域深度**：行业 know-how

### 11.3 进化方向
- **分析师 → 商业决策者**：从数据到战略
- **分析师 → 数据科学家**：补机器学习技能
- **分析师 → 数据产品经理**：建数据产品
- **分析师 → AI 训练师**：用 AI 提升分析效率
