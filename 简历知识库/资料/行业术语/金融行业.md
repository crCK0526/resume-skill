# 金融行业 - 专业术语词典

> 适用岗位：投行、券商、行研、基金、咨询、风控、保险、银行、审计
> 适用人群：金融、经济、数学相关专业的应届生
> 整理日期：2026-09-02

---

## 一、金融行业分类

### 1.1 卖方 (Sell-Side)
- **投资银行 (IB, Investment Banking)**：股票 / 债券承销、并购顾问
- **券商**：经纪业务、自营、资管
- **研究所 / 行研 (Equity Research)**：股票研究、行业研究
- **销售交易 (Sales & Trading, S&T)**：股票 / 债券 / 衍生品交易

### 1.2 买方 (Buy-Side)
- **公募基金 (Mutual Fund)**：二级市场投资
- **私募基金 (Hedge Fund / Private Equity)**：对冲基金 / 私募股权
- **VC (Venture Capital)**：风险投资
- **险资 (Insurance Asset Management)**：保险资金运用
- **信托 (Trust)**：信托公司

### 1.3 其他金融
- **银行（商行 / 投行）**
- **保险**
- **PE / VC 投资**
- **资产管理 (Asset Management)**
- **金融科技 (FinTech)**
- **信用评级 (Rating Agency)**

## 二、投行 / 券商必备技能

### 2.1 核心技能
- **财务建模 (Financial Modeling)**：三张表模型 / DCF / LBO
- **估值 (Valuation)**：DCF / 可比公司 / 可比交易
- **Excel 高级应用**：VBA、宏、快捷键
- **PPT 制作**：Pitch Book / Deal Book
- **行业研究 (Industry Research)**
- **尽职调查 (Due Diligence)**
- **招股书 / 募集说明书**
- **Pitch Deck 设计**

### 2.2 估值方法
- **DCF (Discounted Cash Flow)**：现金流折现
  - WACC (Weighted Average Cost of Cost)
  - Terminal Value
- **可比公司分析 (Trading Multiples)**：P/E、P/B、EV/EBITDA
- **可比交易分析 (Transaction Multiples)**
- **NAV (Net Asset Value)**
- **SOTP (Sum of the Parts)**：分部加总
- **LBO (Leveraged Buyout)**：杠杆收购
- **Acreage / 资源价值法**

### 2.3 财务三张表
- **利润表 (Income Statement)**
  - 营业收入 / 营业成本 / 毛利 / 期间费用 / 净利润
- **资产负债表 (Balance Sheet)**
  - 资产 / 负债 / 所有者权益
  - 流动 / 非流动
- **现金流量表 (Cash Flow Statement)**
  - 经营 / 投资 / 筹资活动现金流

## 三、行研核心技能

### 3.1 必备工具
- **Wind / Bloomberg / Choice**：金融数据终端
- **iFinD / 东方财富 / 同花顺**
- **巨潮资讯网 (cninfo.com.cn)**：公告
- **公司年报 / 招股书 / 季报**
- **行业数据来源**：国家统计局、行业协会、产业在线
- **Excel / PowerPoint / Word**

### 3.2 行研报告结构
- **行业概况**（市场空间 / 增速 / 集中度）
- **竞争格局**（主要玩家 / 市场份额）
- **产业链分析**（上游 / 中游 / 下游）
- **公司分析**（业务 / 财务 / 估值）
- **投资建议**（买入 / 增持 / 持有 / 卖出）
- **风险提示**

### 3.3 估值模型
- **DCF 模型**
- **相对估值法**（P/E, P/B, EV/EBITDA, P/S）
- **PEG 估值**
- **DDM 模型**（Dividend Discount Model）
- **PB-ROE 估值**

## 四、基金 / 投资核心技能

### 4.1 投资分析
- **宏观经济分析**：GDP、CPI、PMI、M2
- **行业分析**：行业生命周期、波特五力、SWOT
- **公司分析**：商业模式、护城河、管理层
- **财务分析**：杜邦分析、现金流质量

### 4.2 投资策略
- **价值投资**：巴菲特、格雷厄姆
- **成长投资**：费雪、彼得·林奇
- **GARP 策略**：合理价格成长
- **量化投资**：因子模型、统计套利
- **事件驱动**：并购、重组、定增
- **CTA 策略**：商品期货

### 4.3 必备证书
- **CFA (Chartered Financial Analyst)**：金融分析师
- **FRM (Financial Risk Manager)**：金融风险管理
- **CPA (Certified Public Accountant)**：注册会计师
- **ACCA**：国际注册会计师
- **证券从业 / 基金从业 / 期货从业**（国内必考）
- **保荐代表人**（投行）
- **司法考试**（合规、风控）

---

## 五、风控 / 审计核心技能

### 5.1 风控
- **信用风险**：违约率、PD、LGD、EAD
- **市场风险**：VaR、ES、Beta
- **操作风险**：流程管控、KRI
- **巴塞尔协议 / IFRS 9**
- **压力测试 (Stress Testing)**
- **模型验证 (Model Validation)**

### 5.2 审计
- **四大会计师事务所**：普华永道、德勤、毕马威、安永
- **审计流程**：风险评估、控制测试、实质性程序
- **审计报告**：无保留 / 保留 / 否定 / 无法表示意见
- **中国会计准则 (CAS) / 国际财务报告准则 (IFRS)**

### 5.3 必备证书
- **CPA（注册会计师）**：国内财会最核心证书
- **ACCA**：国际认可
- **CFA**：金融分析
- **FRM**：风险管理
- **CIA**：国际注册内部审计师

## 七、金融行业面试高频考点

### 7.1 投行面试
- **估值建模题**：现场搭建 DCF / 可比公司
- **并购案例题**：分析一个真实并购案
- **行业研究题**：覆盖行业的关键驱动因素
- **Excel 测试**：财务建模、敏感性分析
- **行为面试**：Why IB / Why this firm / 3-year plan

### 7.2 行研面试
- **行业分析题**：新能源 / 半导体 / 消费 / 医药
- **公司分析题**：覆盖公司近期业务、财务、估值
- **市场观点题**：怎么看 A 股 / 港股 / 美股
- **行业证书题**：CFA / FRM 内容

### 7.3 基金面试
- **股票推荐题**：推荐 1-2 只股票
- **市场观点**：当前市场怎么看
- **投资理念题**：你的投资风格
- **压力测试题**：市场下跌 20% 你怎么办

## 九、求职时间线

### 9.1 暑期实习（Summer Internship）
- **大三下 3-4 月**：网申开始（投行 / 咨询）
- **大四上 9-10 月**：暑期实习转正
- **部分投行 "Superday"**：5-7 月集中面试

### 9.2 秋招
- **7-8 月**：网申、提前批
- **9-10 月**：宣讲会、网申高峰
- **10-11 月**：笔试、面试
- **11-12 月**：Offer 发放

### 9.3 春招
- **2-3 月**：补招、考研失败党
- **4-5 月**：最后机会

## 十、AI 时代金融人的转型

### 10.1 AI 改变的金融工作
- **基础数据收集**：自动化
- **报告初稿生成**：AI 写作
- **简单估值模型**：自动化建模
- **数据可视化**：AI 生成图表

### 10.2 金融人核心价值（AI 难以替代）
- **行业洞察**：深度行业研究
- **客户关系**：销售、关系维护
- **复杂交易结构设计**：并购、衍生品
- **风险判断**：综合风险评估
- **合规判断**：监管解读

### 10.3 转型方向
- **金融 + AI**：量化投资、算法交易
- **金融 + 科技**：FinTech、区块链
- **金融 + 监管**：合规科技 (RegTech)
- **金融 + 可持续**：ESG 投资、绿色金融
