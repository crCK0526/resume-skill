# 留学申请 - 专业术语词典

> 适用人群：申请海外本科 / 研究生 / MBA 的学生
> 适用目的地：美国、英国、香港、新加坡、欧洲、澳洲、加拿大
> 整理日期：2026-09-02

---

## 一、留学申请核心要素

### 1.1 申请背景
- **GPA (Grade Point Average)**：绩点（核心）
- **标化考试**：TOEFL / IELTS / GRE / GMAT / SAT / ACT
- **科研经历**：论文发表、研究项目、实验室经历
- **实习经历**：行业相关实习
- **推荐信 (Recommendation Letter / RL)**：通常 2-3 封
- **个人陈述 (Personal Statement / PS)**
- **简历 (CV / Resume)**
- **Writing Sample / Essay**（部分项目要求）

### 1.2 申请关键时间节点（美国研究生为例）
- **大一大二**：保持 GPA、参与科研/实习
- **大三上**：确定方向、准备标化
- **大三下 - 大四上**：选校、找推荐人、准备文书
- **大四上 9-12 月**：网申、提交材料
- **大四下 1-3 月**：面试、等待结果
- **大四下 4-7 月**：I-20、签证、入学准备

## 二、标化考试

### 2.1 托福 TOEFL iBT
- **满分 120**（阅读 + 听力 + 口语 + 写作各 30）
- **目标分数**：美国 Top 30 通常 100+，Top 10 通常 105+
- **有效期**：2 年
- **备考周期**：3-6 个月

### 2.2 雅思 IELTS
- **满分 9.0**（听说读写各 9.0）
- **目标分数**：英国 G5 通常 7.0+（单项 6.5+）
- **有效期**：2 年
- **A 类（学术类）/ G 类（培训类）**

### 2.3 GRE (Graduate Record Exam)
- **满分 340**（语文 + 数学各 170）+ 写作 6.0
- **目标分数**：Top 30 通常 325+
- **有效期**：5 年
- **考试内容**：Verbal / Quant / AWA

### 2.4 GMAT (Graduate Management Admission Test)
- **满分 800** + IR 8.0 + AWA 6.0
- **目标分数**：Top MBA 通常 720+
- **有效期**：5 年

### 2.5 SAT / ACT（本科申请）
- **SAT 满分 1600**
- **ACT 满分 36**
- **目标分数**：Top 30 通常 SAT 1450+ / ACT 32+

## 三、留学申请文书

### 3.1 Personal Statement (PS)
- **长度**：800-1200 字
- **结构**：
  - 开头：动机 / 触动事件
  - 主体：背景 + 关键经历 + 能力 + 兴趣
  - 结尾：未来规划 + 与项目的契合
- **核心**：why this program / why this school
- **禁忌**：
  - 罗列经历（CV 已经写了）
  - 空洞套话（"从小我就..."）
  - 抄袭范文（招生官都看过）

### 3.2 推荐信 (Recommendation Letter)
- **数量**：通常 2-3 封
- **推荐人选择**：
  - 学术推荐人（教授、研究导师）
  - 实习推荐人（直属上司、mentor）
- **核心**：具体事例 + 评价 + 你的独特性
- **建议**：提前 1-2 个月沟通，不要突然找

### 3.3 CV / Resume
- **长度**：1-2 页（硕士）/ 2-3 页（博士 / 资深申请者）
- **结构**：
  - 教育背景（学校 / GPA / 排名 / 核心课程）
  - 研究 / 实习经历
  - 论文 / 专利 / 竞赛
  - 技能 / 证书 / 获奖
- **与求职简历区别**：
  - 更突出学术 / 研究能力
  - 期刊论文 / 会议论文要写全
  - 推荐人可以写明

### 3.4 简历常见写法（留学版）
```
教育背景
- 北京大学 计算机科学 GPA: 3.8/4.0 (Top 5%)
- 核心课程：算法、数据结构、机器学习、操作系统

研究经历
- 北京大学机器学习实验室 研究助理 2024.06 - 至今
  导师：Prof. XXX
  - 主导 XXX 课题研究，提出 XXX 算法，效率提升 30%
  - 第一作者发表论文于 XXX 会议（CCF-A 类）

实习经历
- 字节跳动 算法实习生 2024.07 - 2024.09
  - 参与 XXX 推荐系统优化，提出 XXX 改进方案
  - 申请 1 项专利，落地 2 个核心场景

论文 / 专利
- [1] 第一作者. XXX. NeurIPS 2024.（CCF-A 类）

技能
- 编程：Python, C++, PyTorch, TensorFlow
- 工具：Git, Docker, Linux
- 语言：英语（CET-6 600+）/ 托福 108
```

## 四、各国 / 地区申请要点

### 4.1 美国研究生（最卷）
- **Top 30 申请要求**：
  - GPA 3.7+（985）/ 3.9+（211）
  - TOEFL 100+ / GRE 325+
  - 2-3 段科研经历
  - 1 段以上海外交换 / 暑研
  - 1-2 段行业实习
  - 1-2 篇论文（顶会顶刊加分）
- **申请时间**：9-12 月集中申请
- **截止日期**：12.15 / 1.1 / 1.15 几个关键点

### 4.2 英国研究生
- **G5 申请要求**：
  - GPA 85+（985）/ 88+（211）/ 90+（双非）
  - IELTS 7.0+（单项 6.5+）
  - 部分专业需要 GMAT/GRE
- **申请时间**：滚动招生，先到先得
- **截止日期**：通常 1-3 月（热门项目更早）
- **特殊**：几乎不要求面试，部分学校接受无语言申请（先发 conditional offer）

### 4.3 香港 / 新加坡
- **港三新二**：
  - GPA 85+（985/211）/ 88+（双非）
  - TOEFL 100+ / IELTS 7.0+
  - 2 段以上实习 / 科研
  - 1-2 段名企 / 海外经历加分
- **申请时间**：9-12 月集中
- **截止日期**：通常分轮次（Round 1: 10-11 月，Round 2: 12-1 月）
- **特殊**：港大 / 港中文部分专业有面试

### 4.4 澳洲 / 加拿大
- **G8 / Top 3**：
  - GPA 80+
  - IELTS 6.5-7.0
  - 申请门槛相对友好
- **优势**：移民政策友好，毕业后工作签证
- **申请时间**：全年可申

### 4.5 欧洲（德国 / 法国 / 北欧）
- **优势**：免学费 / 低学费（德国、北欧部分）
- **劣势**：语言要求严（德语 / 法语 / 当地语言）
- **英语项目**：商科 / 工程 / 计算机有英语授课

## 五、热门专业申请背景要求

### 5.1 计算机科学 (CS)
- **核心课程**：算法、数据结构、操作系统、网络、AI
- **加分项**：顶会论文（NeurIPS / ICML / CVPR / ACL）、Kaggle 竞赛、GitHub 项目
- **实习**：大厂算法 / 工程实习
- **科研**：海外暑研（MIT / Stanford / CMU）

### 5.2 数据科学 / 商业分析 (DS / BA)
- **核心课程**：统计、机器学习、SQL、Python
- **加分项**：商业分析项目、咨询公司实习
- **工具**：Python / R / SQL / Tableau
- **证书**：Google Data Analytics、AWS ML Specialty

### 5.3 金融 / 金融工程
- **核心课程**：金融工程、计量经济学、衍生品定价
- **加分项**：CFA / FRM（通过一级加分）
- **实习**：投行 / 券商 / 四大 / 咨询
- **数学背景**：高数 / 线代 / 概率统计

### 5.4 商业分析 / MBA
- **核心背景**：工作经历 3-5 年+
- **GMAT**：720+
- **推荐信**：直属上司 + 跨部门合作者
- **文书**：career goal + leadership 故事

### 5.5 法律 (LLM / JD)
- **LLM（一年制硕士）**：法本 + 托福 / 雅思
- **JD（美国 3 年制博士）**：LSAT 170+
- **核心课程**：宪法、合同法、侵权法
- **加分项**：模拟法庭、法律诊所

## 六、留学申请避坑指南

### 6.1 选校策略
- ❌ 全部冲刺 Top 10（风险大）
- ❌ 全部保底校（浪费申请费）
- ✅ **冲刺 + 主申 + 保底 = 3:5:2 比例**
  - 冲刺 3 所（Top 10）
  - 主申 5 所（Top 11-30）
  - 保底 2 所（Top 31-50）

### 6.2 文书避坑
- ❌ 一篇 PS 申请 10 个学校（招生官能看出来）
- ❌ PS 罗列经历（缺乏故事性）
- ❌ 没有 why school 具体内容
- ✅ 每个项目都定制，深度匹配

### 6.3 推荐信避坑
- ❌ 找不熟的老师写（内容空洞）
- ❌ 推荐信模板化
- ✅ 找熟悉你的老师 + 提供素材（你的简历、文书、亮点）

## 八、奖学金与助学资源

### 8.1 美国
- **Fellowship / Assistantship**：全奖 + 学费 + 生活费
- **TA / RA**：Teaching / Research Assistantship
- **CSC（国家留学基金委）**：公派留学
- **校级奖学金**：Merit-based / Need-based

### 8.2 英国
- **Chevening 志奋领奖学金**（英国政府，全奖）
- **Commonwealth Scholarship**
- **校级奖学金**：Oxford Clarendon / Cambridge Gates Cambridge

### 8.3 香港
- **港府奖学金 (HKPFS)**：全奖
- **校级奖学金**

## 九、留学后职业发展

### 9.1 美国
- **OPT**：12 个月工作签证
- **STEM OPT**：延长 24 个月（合计 36 个月）
- **H1B 工作签证**：抽签制

### 9.2 英国
- **Graduate Visa**：2 年工作签证（PSW）
- **PhD 毕业生**：3 年

### 9.3 香港
- **IANG**：1 年签证，续签 2+2+3 年
- **满 7 年可拿永居**

### 9.4 回国就业
- **留学生身份优势**：
  - 一线城市落户（北京 / 上海 / 深圳 / 杭州）
  - 高校 / 国企 / 大厂招聘偏好
  - 海归人才补贴（部分城市）
