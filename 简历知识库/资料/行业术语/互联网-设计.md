## 一、UX（用户体验）核心术语

### 1.1 用户研究
- **用户访谈 (User Interview)**：1v1 深度访谈
- **问卷调查 (Survey)**：定量研究
- **焦点小组 (Focus Group)**：6-8 人小组讨论
- **可用性测试 (Usability Testing)**：观察用户使用产品
- **A/B 测试**：双版本对比
- **眼动测试 (Eye Tracking)**
- **用户画像 (Persona)**
- **用户旅程地图 (User Journey Map)**
- **同理心地图 (Empathy Map)**
- **触点分析 (Touchpoint Analysis)**

### 1.2 信息架构
- **信息架构 (IA, Information Architecture)**
- **导航设计 (Navigation)**
- **站点地图 (Sitemap)**
- **分类法 (Taxonomy)**
- **卡片分类法 (Card Sorting)**
- **树形测试 (Tree Testing)**
- **搜索体验 (Search Experience)**
- **标签系统 (Tagging System)**
- **筛选 / 排序 / 分页**

### 1.3 交互设计
- **交互原型 (Interactive Prototype)**
- **用户流程图 (User Flow)**
- **状态机图 (State Machine)**
- **线框图 (Wireframe)**
  - 低保真 (Lo-fi)
  - 中保真 (Mid-fi)
  - 高保真 (Hi-fi)
- **交互规范 (Interaction Spec)**
- **微交互 (Micro-interaction)**
- **动效设计 (Motion Design)**
- **空状态 / 错误状态 / 加载状态**
- **响应式设计 (Responsive Design)**
- **可访问性 (Accessibility, a11y / WCAG)**

## 二、UI（用户界面）核心术语

### 2.1 设计基础
- **版式设计 (Layout)**
- **栅格系统 (Grid System)**
- **色彩理论 (Color Theory)**
  - 主色 / 辅色 / 强调色 / 中性色
  - 色相 / 饱和度 / 明度
- **字体排版 (Typography)**
  - 衬线体 (Serif) / 无衬线体 (Sans-serif)
  - 字重 / 行高 / 字距
  - 字号系统 (Material Design 推荐 12-16sp)
- **图标系统 (Icon System)**
  - 线性 / 面性 / 拟物
  - 16/24/32px 网格规范
- **间距系统 (Spacing System)**
  - 4px / 8px 基准
- **圆角 / 阴影 / 渐变**

### 2.2 设计系统
- **设计系统 (Design System)**
- **组件库 (Component Library)**
- **设计规范 (Design Guideline)**
- **设计令牌 (Design Tokens)**
- **样式指南 (Style Guide)**
- **品牌手册 (Brand Book)**
- **Pattern Library**
- **Storybook**

### 2.3 设计原则
- **一致性 (Consistency)**
- **可预测性 (Predictability)**
- **可学习性 (Learnability)**
- **容错性 (Error Tolerance)**
- **效率 (Efficiency)**
- **审美 (Aesthetics)**
- **希克定律 (Hick's Law)**
- **菲茨定律 (Fitts's Law)**
- **米勒定律 (Miller's Law)**
- **雅各布定律 (Jakob's Law)**
- **格式塔原则 (Gestalt Principles)**

## 四、设计师分类与必备技能

### 4.1 UI 设计师
- **核心技能**：Figma / Sketch、视觉设计、设计系统
- **加分项**：插画、品牌设计、动效、CSS
- **作品集要求**：2-3 个完整 UI 项目 + 设计系统

### 4.2 UX 设计师
- **核心技能**：用户研究、流程图、原型、可用性测试
- **加分项**：数据分析、A/B 测试、服务设计
- **作品集要求**：2-3 个完整 Case Study（问题-研究-方案-验证）

### 4.3 视觉/品牌设计师
- **核心技能**：品牌设计、平面设计、海报、VI 系统
- **加分项**：插画、动效、3D
- **作品集要求**：品牌项目、平面作品、视觉规范

### 4.4 交互设计师
- **核心技能**：交互原型、动效设计、微交互
- **加分项**：代码基础（HTML/CSS/JS）
- **作品集要求**：复杂交互案例、动效 Demo

### 4.5 全栈设计师 / Design Engineer
- **核心技能**：设计 + 前端（React/Vue）
- **加分项**：动效代码、WebGL、AI 工具
- **作品集要求**：上线产品 + 完整代码

## 五、设计行业简历加分亮点

### 5.1 设计师简历的 5 个核心要素
1. **简历与作品集分工**：简历呈现可扫描事实，作品集证明审美、过程与成品质量。
2. **作品集入口清晰**：页首提供可点击文字 URL；二维码只能作为补充。
3. **成果可验证**：有可靠数据时量化，没有数据时写清交付物、上线、采用、验收或获奖结果。
4. **系统与流程思维**：说明从问题、方法到交付的完整链路，而不只展示最终画面。
5. **跨职能协作能力**：明确与产品、研发、导演、编剧、运营、声音或客户的协作边界。

### 5.2 优秀设计简历示例
- **"主导平台改版设计，使客户留存率从 64% 提升至 78%，覆盖 22 万活跃用户"**
- **"搭建 60 个组件的 Figma 设计系统，7 名产品设计师共用，减少设计-工程交付时间从 4 天到 1 天"**
- **"通过 8 次可用性测试识别 12 个关键导航问题，重构信息架构后用户完成率提升 25%"**
- **"设计的核心转化漏斗，使新用户首周激活率从 35% 提升至 60%"**

## 六、设计师作品集建议

### 6.1 必备元素
- 选择少量、与目标岗位高度相关的代表项目；不设适用于所有岗位的固定项目数量。
- UI/UX 项目可使用：问题 → 研究 → 方案 → 验证 → 结果。
- 视觉/品牌项目可使用：目标 → 概念 → 视觉系统 → 应用场景 → 成品。
- 影视/AIGC 项目可使用：命题/剧本 → 分镜 → 角色与画面一致性 → 生成/拍摄 → 剪辑调色 → 声音 → 成片。
- 每个项目明确个人角色、团队规模、使用工具、交付物和结果。
- 作品集项目名、日期、角色必须与简历一致。

### 6.2 作品集平台
- **个人网站 / 独立域名**（最专业）
- **Behance / Dribbble**（国际曝光）
- **站酷 / UI 中国**（国内曝光）
- **Figma Community**（免费发布）
- **Notion / 语雀**（快速搭建）

### 6.3 影视 / AIGC / 新媒体术语

- **前期**：创意提案、剧本拆解、分镜脚本、镜头设计、角色设定、视觉开发。
- **生成与制作**：文生图、图生视频、参考图控制、角色一致性、镜头连续性、提示词工程、工作流编排。
- **后期**：粗剪、精剪、多轨剪辑、调色、LUT、合成、字幕、声音设计、混音、交付编码。
- **常见交付物**：分镜表、角色设定图、关键帧、镜头素材、成片、横竖版适配、项目复盘。
- **风险词**：“一键生成”“全流程主导”“电影级”等词只有在有完整证据时使用；工具名不能替代能力和作品证明。

### 6.4 简历双轨交付

- **ATS 主投版**：单栏优先、文本可提取、作品集文字 URL、结构清晰。
- **创意展示版**：可使用更强视觉语言，但最小字号、文本顺序和事实密度仍需可读。
- 两个版本共享同一事实台账，不能出现项目日期、角色和结果不一致。

## 九、AI 时代设计师的转型方向

### 9.1 AI 改变的设计工作
- **AI 生成 UI**：Figma AI、Galileo AI 自动生成界面
- **AI 绘图**：Midjourney 替代基础插画
- **AI 写文案**：基础营销文案自动化
- **AI 切图 / 标注**：自动设计交付

### 9.2 设计师核心价值（AI 难以替代）
- **策略性思考**：商业目标 → 设计策略
- **共情能力**：理解用户情感
- **跨职能协调**：与 PM / RD / 业务沟通
- **品牌战略**：建立长期品牌资产
- **复杂创新**：AI 无法解决的真问题

### 9.3 设计师的进化路径
- **传统 UI → 体验设计师**：从"好看"到"好用"
- **视觉 → 品牌**：从单个页面到品牌体系
- **设计师 → Design Engineer**：设计与代码融合
- **设计师 → 产品经理**：设计与业务融合
- **设计师 → AI 训练师 / Prompt Engineer**：用 AI 提升设计效率
