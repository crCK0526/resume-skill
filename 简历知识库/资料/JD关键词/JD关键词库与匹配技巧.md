## 一、为什么 JD 关键词至关重要

> **ATS 简历筛选系统 75% 靠关键词匹配**——你的简历上没有 JD 提到的核心词，直接被机器 pass 掉，HR 永远看不到。

**真实数据**：
- ATS 平均 0.5 秒决定一份简历去留
- 关键词命中率 < 60% 的简历 90% 被刷
- 关键词命中率 > 80% 的简历通过率提升 3 倍

## 二、JD 关键词分类

### 2.1 必备词（必须完全匹配）
- **技术栈**：Spring Boot、MySQL、Redis、Kafka、Python、TensorFlow
- **岗位名称**：产品经理、Java 开发、数据分析师、UI 设计师
- **核心技能**：用户调研、PRD 撰写、SQL 查询、A/B 测试
- **行业经验**：电商、SaaS、金融科技、教育

### 2.2 加分词（出现 50%+ 即可）
- **方法论**：敏捷开发、Scrum、MVC 架构
- **工具**：Axure、Figma、Tableau、Jira
- **能力**：跨部门协作、数据驱动、抗压能力

### 2.3 软技能词（点缀用）
- 沟通能力、团队合作、学习能力
- ⚠️ **不要堆砌**：所有简历都有，意义不大
- ✅ **必须配案例**：「沟通能力强」是空话，「主导 5 人团队完成 XX 项目」是事实

## 四、关键词匹配技巧

### 4.1 提取 JD 关键词（4 步法）
1. **通读 JD 3 遍**：理解整体意图
2. **荧光笔标记**：所有名词 + 动词
3. **分类整理**：技术 / 工具 / 能力 / 行业
4. **优先级排序**：哪些是必备、哪些是加分

### 4.2 简历嵌入关键词的 5 个位置
1. **个人简介（Summary）**：2-3 个核心关键词
2. **技能栏**：80% 关键词 + 完整写法
3. **工作经历**：每段 2-3 个关键词（用 STAR）
4. **项目经历**：标题包含核心关键词
5. **自我评价**：1-2 个软技能 + 案例

### 4.3 关键词密度建议
- **必备词**：100% 出现（必须）
- **加分词**：50-70% 出现
- **软技能词**：20-30%（不要堆砌）
- **不相关词**：0%（不要凑数）

### 4.4 关键词匹配自查清单
- [ ] JD 中所有"技术栈"词都在简历出现
- [ ] JD 中"核心技能"在 STAR 里有具体体现
- [ ] JD 中"行业经验"在经历中明确提及
- [ ] JD 中"工具"在技能栏列出
- [ ] 没有为了凑关键词而堆砌无关技能

## 五、JD 关键词反推流程

### 5.1 拿到 JD 后第一步
```
原文（JD） →
  ↓ 提取关键词
关键词清单（按优先级） →
  ↓ 对照简历
差距分析（缺失 / 已覆盖） →
  ↓ 改写简历
针对性版本 v1
```

### 5.2 实操示例

**JD 原文**：
> "负责抖音电商业务的数据分析，使用 SQL 进行数据提取，搭建 Tableau 仪表盘，与业务团队协作推动数据决策。"

**关键词提取**：
- 必备：数据分析、SQL、Tableau 仪表盘
- 加分：抖音电商、业务协作、数据决策

**简历改写**：
- ❌ 原版："熟练使用 SQL 和 Tableau"
- ✅ 改版："主导抖音电商业务数据分析，使用 SQL 提取日均 1 亿条数据，搭建 Tableau 仪表盘覆盖 5 个核心指标，与产品 / 运营团队协作推动 3 次业务决策，单次活动 GMV 提升 20%"

## 六、不同岗位的关键词策略

### 6.1 应届生
- **多写"潜力"关键词**：学习能力、抗压、实习经历
- **学校关键词**：985/211、海归、奖学金
- **基础技能关键词**：Office、Python 基础、SQL 基础

### 6.2 1-3 年经验
- **突出"项目"关键词**：独立负责、主导、推动
- **技能关键词**：熟练使用（不是"了解"）
- **业务关键词**：行业经验、用户量、GMV

### 6.3 5+ 年经验
- **突出"战略"关键词**：规划、体系、团队管理
- **管理关键词**：带过 X 人团队、负责 X 业务
- **结果关键词**：创造 X 收益 / 节约 X 成本

## 七、关键词不匹配的 5 种信号

1. ❌ **JD 多次提到"数据分析"但简历 0 个数据分析项目**
2. ❌ **JD 要求"Spring Cloud"但你只有"SSH 框架"经验**
3. ❌ **JD 写"互联网行业经验"但你只写"传统行业"**
4. ❌ **JD 强调"用户增长"但你的经历都是"产品设计"**
5. ❌ **JD 要求"5 年以上"但你只写"3 年"**

**解决**：诚实评估是否匹配，不匹配就别投。

## 八、AI 工具辅助

### 8.1 本地优先
- 先用本地文本提取、词频统计和人工对照识别 JD 中的职责、工具、交付物与行业词。
- 只匹配本人真实具备且能够举证的关键词。

### 8.2 第三方工具
- Resume Worded、Jobscan 等可提供简历-JD 对照或解析提示，但其评分不代表真实雇主 ATS 或录用结果。
- 其他 AI 简历工具也只能作为改写建议来源，不能自动补造量化成果。

### 8.3 使用注意
- 默认不上传真实简历或个人信息。
- 使用在线工具前，核验服务方、隐私政策、数据保留、训练用途和删除机制，说明具体上传字段并获得用户明确授权。
- AI 工具是辅助，不是替代；输出必须经过事实台账和人工复核。
- 保持个人表达，避免“千篇一律”。

## 九、关键词避坑指南

### 9.1 不要堆砌关键词
❌ "熟悉 Python、Java、Go、Rust、JavaScript、TypeScript、C++、C#、Ruby、PHP..."
（看似 10 项技能，实际都不精通）

### 9.2 不要写模糊词
❌ "熟悉大数据相关技术"
✅ "熟悉 Hadoop / Spark / Flink，了解 ClickHouse / Doris"

### 9.3 不要写错版本
❌ "熟悉 Spring"
✅ "熟悉 Spring Boot 3.x / Spring Cloud 2023"

### 9.4 不要写"了解"
❌ "了解 MySQL"
✅ "熟练使用 MySQL（含索引优化、慢查询分析）" 或 "使用 MySQL 完成 XX 项目"

### 9.5 不要写无关技能
❌ 求职 Java 后端，写了"熟练使用 Pr / Photoshop"
（无关技能暴露简历不专业）
