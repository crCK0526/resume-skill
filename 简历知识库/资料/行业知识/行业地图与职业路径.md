## 一、互联网行业地图（2026）

### 1.1 主要细分领域

```
互联网
├── 互联网公司（BAT、字节、美团、滴滴等）
│   ├── 核心业务：搜索 / 电商 / 社交 / 资讯 / 娱乐
│   └── 子领域：算法 / 后端 / 前端 / 产品 / 设计 / 运营 / 数据
│
├── 科技 / 硬科技
│   ├── AI 大模型：OpenAI 类 / 国内大模型六虎（智谱、月之暗面等）
│   ├── 半导体：芯片设计 / 制造 / 封装
│   ├── 机器人：人形机器人 / 工业机器人 / 服务机器人
│   └── 自动驾驶：L4 出租车 / 城市 NOA / 物流
│
├── 新兴互联网
│   ├── 跨境电商：Temu / Shein / TikTok Shop
│   ├── 出海应用：短剧 / 社交 / 工具
│   ├── 数字内容：AIGC / 短视频 / 直播
│   └── Web3：区块链 / 数字藏品 / RWA
│
└── 行业互联网（产业互联网）
    ├── 金融科技（FinTech）
    ├── 医疗互联网（互联网医院 / AI 制药）
    ├── 教育科技（EdTech / AI 辅导）
    └── 企业服务（SaaS / PaaS / 云计算）
```

### 1.2 互联网热门岗位（2026 需求 TOP 10）

1. **AI 工程师**（大模型 / Agent 方向）：月薪 30-80K
2. **算法工程师**（推荐 / NLP / CV）：月薪 25-60K
3. **后端开发**（Java / Go）：月薪 20-50K
4. **产品经理**（AI 产品 / 增长）：月薪 20-50K
5. **数据分析师**：月薪 15-35K
6. **前端开发**（React / Vue）：月薪 15-40K
7. **运营**（用户 / 内容 / 增长）：月薪 12-30K
8. **UI/UX 设计师**：月薪 15-35K
9. **测试工程师**（自动化 / 性能）：月薪 12-30K
10. **运维 / SRE**：月薪 15-35K

## 二、金融行业地图

### 2.1 金融行业分类

```
金融
├── 银行业
│   ├── 国有大行：工农中建交邮
│   ├── 股份制：招商、浦发、兴业、中信
│   └── 城商行 / 农商行
│
├── 证券业
│   ├── 头部券商：中金、中信、华泰、国君、海通
│   ├── 外资投行：高盛、摩根士丹利、UBS
│   └── 精品投行：Lazard、Evercore、Moelis
│
├── 基金业
│   ├── 公募基金：易方达、广发、华夏、嘉实
│   ├── 私募证券：但斌、林园、葛卫东等
│   ├── 私募股权（PE）：红杉、IDG、高瓴、源码
│   └── 创投（VC）：真格、创新工场、英诺天使
│
├── 保险业
│   ├── 寿险：平安、国寿、太保、太平
│   └── 财险：人保、平安、太保
│
└── 其他金融
    ├── 信托：中信、平安、上海信托
    ├── 资管：银行理财子、券商资管、保险资管
    └── 金融科技（FinTech）：蚂蚁、京东金融、度小满
```

### 2.2 金融行业职业路径

```
分析师 / 客户经理
  ↓ (2-3 年)
高级分析师 / 经理
  ↓ (3-5 年)
副总裁（VP）/ 高级经理
  ↓ (5-8 年)
董事总经理（MD）/ 合伙人
  ↓ (8-15 年)
首席 / 合伙人 / 机构负责人
```

**典型薪资**：
- 应届分析师：30-60 万 / 年（一线）
- 经理：80-150 万 / 年
- VP：200-400 万 / 年
- MD：400-1000 万 / 年

## 四、互联网职业路径详解

### 4.1 技术岗路径

```
初级开发工程师 0-2 年
  ↓
高级开发工程师 2-5 年
  ↓
技术专家 / 架构师 5-8 年
  ↓
技术总监 / CTO 8+ 年
```

**关键能力节点**：
- 0-2 年：扎实基础（语言、框架、工具）
- 2-5 年：独立负责模块、系统设计能力
- 5-8 年：技术选型、跨团队协调、培养新人
- 8+ 年：技术战略、商业敏感度

### 4.2 产品岗路径

```
产品助理 / 实习生 0-1 年
  ↓
产品经理 1-3 年
  ↓
高级产品经理 4-6 年
  ↓
产品总监 / VP 7+ 年
```

**关键能力节点**：
- 0-1 年：执行力、需求分析
- 1-3 年：独立负责功能、用户思维
- 4-6 年：业务理解、数据驱动、跨部门推动
- 7+ 年：产品战略、团队管理、商业洞察

### 4.3 运营岗路径

```
运营专员 0-2 年
  ↓
运营经理 3-5 年
  ↓
运营总监 5-8 年
  ↓
COO / VP 8+ 年
```

**关键能力节点**：
- 0-2 年：执行、数据分析
- 3-5 年：用户增长、活动策划
- 5-8 年：体系搭建、团队管理
- 8+ 年：业务战略、生态构建

### 4.4 设计岗路径

```
UI/UX 设计师 0-3 年
  ↓
高级设计师 3-5 年
  ↓
设计主管 / 专家 5-8 年
  ↓
设计总监 8+ 年
```

**关键能力节点**：
- 0-3 年：基础设计、工具熟练

## 五、应届生求职时间线（2026）

### 5.1 秋招（7-12 月）— 黄金期

| 时间 | 事件 |
|---|---|
| 6-7 月 | 提前批（部分大厂） |
| 7-8 月 | 互联网大厂秋招开放 |
| 8-9 月 | 网申、宣讲会高峰 |
| 9-10 月 | 笔试、面试 |
| 10-11 月 | Offer 发放 |
| 12 月 | 补录、调剂 |

### 5.2 春招（2-5 月）— 补录期

| 时间 | 事件 |
|---|---|
| 2 月 | 春招开放 |
| 3-4 月 | 笔试、面试 |
| 5 月 | 最后机会 |

### 5.3 暑期实习（3-6 月申请，7-9 月实习）

- 大厂暑期实习是"提前批校招"
- 拿到 return offer 的概率 > 70%
- 优秀实习生可跳过秋招

### 5.4 求职准备时间线

| 时间 | 准备内容 |
|---|---|
| 大二下 | 实习、刷题、积累项目 |
| 大三上 | 秋招实习申请、积累技术深度 |
| 大三下 | 暑期实习、刷 leetcode |
| 大三暑假 | 大厂实习 |
| 大四上 | 秋招（主战场） |
| 大四下 | 春招补录、毕业设计 |

## 七、行业趋势与机会（2026）

### 7.1 上升行业
- ✅ **AI / 大模型**：人才缺口巨大，薪资飞涨
- ✅ **新能源 / 储能**：政策支持，扩招
- ✅ **机器人 / 自动驾驶**：技术成熟，岗位增加
- ✅ **跨境电商 / 出海**：高速增长
- ✅ **半导体**：国产替代
- ✅ **生物医药**：创新药

### 7.2 平稳行业
- ⚖️ **互联网整体**：增长放缓但稳定
- ⚖️ **金融**：监管严格
- ⚖️ **教育**：双减政策影响
- ⚖️ **房地产**：下行

### 7.3 衰退行业
- ❌ **K12 学科培训**：受双减影响
- ❌ **互联网金融**：监管收紧
- ❌ **传统媒体**：数字化冲击
- ❌ **低端制造**：自动化冲击

## 八、行业选择建议

### 8.1 选行业的 5 个维度
1. **行业增速**：5 年 CAGR > 10% 优先
2. **薪资中位数**：参考 50 分位 / 75 分位
3. **进入门槛**：学历 / 专业 / 经验要求
4. **工作强度**：996 / 955 / 弹性
5. **长期发展**：5-10 年不被替代

### 8.2 应届生选行业的建议
- **优先大行业 + 热门岗位**（互联网 / 金融 / 咨询）
- **不必太在乎细分赛道**（3 年内会变）
- **看直属 leader**（决定成长速度）
- **看培训体系**（决定天花板）

### 8.3 跳槽换行业
- **横向换**：难度低（互联网 → 互联网细分）
- **纵向换**：难度高（互联网 → 金融）
- **跨行业换**：建议先内部转岗，再外部跳槽
