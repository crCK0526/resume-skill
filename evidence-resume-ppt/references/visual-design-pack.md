# Resume Visual Design Pack — 简历视觉包装风格库

> 版本：2026-09-03
> 定位：`evidence-resume-ppt` 的可选视觉包装层。仅在用户要求“包装/美化/换风格”或给出创意岗位目标时读取。
> 边界：本文件只定义**视觉规范（tokens/版式/字体）**，不提供任何候选人事实。所有颜色、字号与结构规则属于可调设计约定，不构成对 ATS、打印或录用结果的保证。

---

## 0. 使用流程

1. 确定候选人的**投递渠道与目标岗位**，先选定交付轨道：ATS 主投版（浅色、单栏优先）或创意展示版。
2. 询问或推断风格偏好；无偏好时默认沿用参考简历视觉系统，或使用 **Pack A 专业蓝** 基线。
3. 读取本文件对应风格包，将 token 映射为 PPTX 颜色/字号参数。
4. 生成后必须做「渲染检查 + 对比度/灰度检查」；展示版需同时交付 ATS 浅色版。
5. 所有编辑物保持可编辑，禁止整页位图当正文。

---

## 1. 共享设计令牌（三包通用）

### 1.1 画布与网格

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | A4 竖版 21.0 × 29.7 cm | 单页 |
| 安全边距 | 1.4–1.7 cm（约 0.55–0.67 in） | A4 PPTX 基线；不牺牲正文字号换取内容 |
| 网格基距 | 0.08 cm（≈4 px） | 所有间距取基距整数倍 |
| 栏结构 | 顶部信息块可双栏；正文默认单栏 | 双栏仅用于顶部或低风险区域 |

### 1.2 字号阶梯（PPTX 中文）

| 角色 | 范围 |
|---|---|
| 姓名主标题 | 20–26 pt |
| 页眉标签 / 章节标题 | 11–13 pt，加粗 |
| 条目标题（公司/岗位/奖项） | 10–11 pt，加粗 |
| 正文与日期 | 9.5–10.5 pt（硬下限 9 pt） |

### 1.3 字体回退链

| 环境 | 首选 | 回退 |
|---|---|---|
| Windows | 微软雅黑 / 等线 | 思源黑体（Noto Sans SC） |
| macOS | 苹方（PingFang SC） | 思源黑体 |
| 开源/无微软字体 | Noto Sans SC（思源黑体） | Source Han Sans |
| 衬线点缀（仅影视/editorial 标题） | Noto Serif SC / 思源宋体 | 宋体（SimSun，仅兜底） |

生成前确认回退字体是否已安装；渲染图出现缺字或替换即打回。

### 1.4 对比度与灰度门禁

- 正文/辅助文字与背景对比度目标 ≥ 4.5:1（WCAG AA）；大标题与色块文字 ≥ 3:1 仅限装饰用途。
- 交付前做一次**灰度预览**：深色风格在灰度下仍须可读；彩色的语义不能只靠色相表达（颜色不作为唯一信息通道）。
- 激光/黑白打印场景下，避免大面积深底、细线反白字、低透明度浅灰文字。

### 1.5 ATS 硬约束（所有包适用）

- ATS 主投版：浅色底、标准章节名、文本可提取、关键字段不放入图标/二维码/页眉页脚。
- 展示版允许强视觉，但必须另存一份 ATS 浅色单栏版用于系统投递。
- 技能熟练度禁止用进度条/评分点表示（装饰性 sidebar 除非用户明确要求）。

## 2. Pack A — 专业蓝 Professional Blue（现状基线）

> 定位：通用校招/投递主版本。默认交付轨道 = ATS 主投版。

### 2.1 色彩令牌（与基线一致）

Pack A 直接使用 `assets/a4-resume-spec.txt` 中的基线色彩，不新增颜色：

- bg `#FFFFFF`、primary `#0070C0`、dark `#1F3B63`、light `#8EAADB`、ink `#1E1E1E`、sub `#595959`、line `#C9D4E0`

色彩的唯一来源是 `assets/a4-resume-spec.txt`；如需调整，只改该文件，避免两处漂移。

### 2.2 布局语言

- 顶部：姓名（primary 或 ink）+ 求职方向行；联系区右对齐或单行排布。
- 章节标题：dark 加粗，标题下接 0.5–1 pt 同宽细线（light 或 line），线长与内容栏一致。
- 条目标题：公司/项目名 ink 加粗 + 日期 sub 右对齐。
- 分隔：不使用色块侧栏；可用 0.06–0.1 cm 高度主蓝块点缀页眉小标签。
- 头像：ATS 版不放照片；需要占位时使用线框矩形并标注「待提供照片」。

### 2.3 PPTX 工程注意

- 投影/阴影关或最小化；无渐变大背景。
- 全形状可编辑；主蓝只用于关键元素，保持 ≥ 85% 页面为浅色。

## 3. Pack B — 低饱和创意色 Low-Saturation Creative

> 定位：新媒体/设计向/内容运营岗位的展示版；如需系统投递则配套 Pack A 或浅色主投版。

### 3.1 色彩令牌

| 角色 | Hex | 用途 |
|---|---|---|
| bg | #FAF9F6 | 米白底（非纯白，避免廉价感） |
| surface | #FFFFFF | 卡片/信息块底 |
| ink | #262626 | 正文 |
| sub | #6E6A63 | 次级文字/日期 |
| accent | #5F7A76 | 鼠尾草绿（主强调，低饱和） |
| accent2 | #8A8177 | 暖灰棕（次强调，仅标签/线） |
| line | #E3DED4 | 分割线 |

### 3.2 布局语言

- 允许**受控双栏**：主内容左栏宽、辅助栏（技能/获奖）右栏；阅读顺序从上到下、先左后右，导出后必须验证文本顺序。
- 章节标题：ink 加粗 + accent 小方块或短竖线索引（0.12×0.12cm 正方形前置）。
- 技能/工具用「胶囊标签」：surface 底 + 1pt line 描边 + sub 文字；标签内文字 ≥9pt，不使用彩色填充标签。
- 日期右对齐；作品集/主页用 accent 可点击文本，不用二维码替代。
- 强调规则：accent 只出现在章节索引、姓名下划线、链接三处，避免全页着色。

### 3.3 打印/对比注意

- accent #5F7A76 与白底对比不足 4.5:1 时仅用于 ≥12pt 图形或标签描边；正文一律 ink。
- 米白底上避免纯 #000；统一用 ink #262626 保持一致观感。
- 灰度下 accent 应呈现为中性灰阶，信息不因去色而丢失。

## 4. Pack C — 影视暗色专业风 Film Dark Pro

> 定位：AI 影视/微电影/导演向岗位的**展示版**。不适合批量系统投递；必须配套浅色 ATS 主投版。
> 审美参照：DaVinci/Premiere 等剪辑软件深色界面质感 + 克制的专业蓝强调。

### 4.1 色彩令牌

| 角色 | Hex | 用途 |
|---|---|---|
| bg | #101418 | 页面主底（避免纯黑） |
| panel | #171E26 | 信息块/条目底 |
| surface | #1F2831 | 标签底、悬停块 |
| ink | #EDF0F2 | 正文（主文字用近白） |
| sub | #9AA7B2 | 次级文字/日期（暗底对比需验证） |
| accent | #4C9BE8 | 专业蓝强调（参照 DaVinci 高光蓝） |
| accent-dim | #2E6DA4 | 深强调：时间轴/章节编号 |
| line | rgba(237,240,242,0.12) | 发丝线（PPTX 用 12–15% 灰白透明或 #2A333D） |

### 4.2 布局语言

- 顶部：姓名 ink（可配 accent 下划线）+ 岗位定位；联系方式 sub 单行。
- 章节：左侧 0.06 cm accent-dim 竖条或 `01 / 02` 序列号（accent 12pt 宽字距）+ 章节名 ink 加粗。
- 正文一律 ink 色，不用 sub 承担关键内容；日期 sub 右对齐。
- 作品集入口：页眉右侧或首行放 accent 文字链接「作品集 / reel」。
- 条目可用 panel 底卡片（圆角 0.08–0.12 cm，细 line 描边），卡片内仍为普通文本层级。
- 若含封面式顶部（姓名大字 + 主视觉色带），限制在页面上部 1/5 高度，避免侵占正文空间。

### 4.3 工程/交付注意

- 中文字体：标题可用 Noto Serif SC 做电影感点缀，正文必须黑体系保证可读。
- 阴影仅用于卡片微抬升（0.05cm 偏移内），禁止大面积投影与高饱和渐变。
- 导出 PNG 必须检查：暗底上小字是否糊、透明线是否丢失、灰度打印是否仍分层。
- 交付时同步说明：该版为展示版，系统投递请用配套浅色 ATS 版。

## 5. 交付核对清单（视觉包装）

- [ ] 所选风格包 token 已完整映射（bg/ink/sub/accent/line/字体/字号阶梯）。
- [ ] 正文最小字号 ≥9 pt；关键信息未使用 sub/低对比色。
- [ ] 无文字溢出、裁切、换行异常、字体替换。
- [ ] 图形与文字全部可编辑；无整页位图正文。
- [ ] 展示版（Pack B/C）已确认阅读顺序与文本提取顺序一致。
- [ ] 展示版已配套或计划配套 ATS 浅色主投版。
- [ ] 灰度与对比度抽检通过；颜色不作为唯一信息通道。
- [ ] 作品集/主页使用可点击文字链接；二维码仅作补充。
- [ ] 未引入参考人物、虚构公司或任何非候选人事实。
